# ARKANOID

Вверху поля множество прямоугольных блоков. Внизу горизонтально перемещается каретка. По полю летает «мяч», отражаясь от стен, блоков и каретки. Если мяч попадает вниз (мимо каретки) начисляются отрицательные очки /уменьшается каретка/увеличивается число поражений. Блоки бывают разных типов:

1)	Неразрушаемые. От них мяч просто отскакивает.
2)	Блоки могут быть со спрятанными бонусами: при попадании вертикально вниз падает бонус
3)	Блоки, увеличивающие скорость шарика при столкновении
4)	Блоки имеют уровень здоровья = число попаданий, чтобы блок исчез. За каждое попадание +1 очко игроку, -1 очко здоровья блоку.
5)	Бонусы: меняют размер каретки, меняют скорость шарика, меняют прилипание шарика к каретке. 
6)	Бонус: одноразовое дно для шарика – можно один раз пропустить, дно сработает как каретка, и исчезнет. 
7)	Бонус: шарик в произвольный момент меняет траекторию.
8)	Бонус: появляется двигающий блок, не задевающий при движении остальные блоки (надо проверять коллизии), и живущий до 3 ударов
9)	Бонус: появляется второй шарик, способный оттолкнуться и от первого, и от блоков/стенок

Для сдачи: 1-6 + 9


## Инструкция по сборке проекта (Visual Studio 2022)

### Шаг 1. Настройка стандарта языка
1. Откройте проект в Visual Studio.
2. Нажмите правой кнопкой мыши по проекту "Arkanoid" -> "Свойства".
3. В выпадающем списке сверху выберите "Все конфигурации" и платформу "x64".
4. Перейдите в раздел "Свойства конфигурации" -> "Общие".
5. В строке "Стандарт языка C++" выберите "Стандарт ISO C++17".

### Шаг 2. Подключение заголовочных файлов и библиотек SFML
1. В окне свойств перейдите в раздел "C/C++" -> "Общие".
2. В поле "Дополнительные каталоги включаемых файлов" укажите путь к папке "include" вашей библиотеки SFML.
3. Перейдите в раздел "Компоновщик" -> "Общие".
4. В поле "Дополнительные каталоги библиотек" укажите путь к папке "lib" вашей библиотеки SFML.

### Шаг 3. Указание зависимостей
1. В разделе "Компоновщик" -> "Ввод" найдите строку "Дополнительные зависимости".
2. Нажмите "Изменить" и добавьте в список следующие библиотеки:
   
sfml-graphics.lib

sfml-window.lib

sfml-system.lib
   
3. Нажмите "Применить", а затем "ОК".

### Шаг 4. Добавление динамических библиотек (.dll)
1. Перейдите в папку, где распакован SFML, и откройте каталог "bin".
2. Скопируйте оттуда все файлы.
3. Вставьте их прямо в корневую папку вашего проекта на компьютере (туда, где лежат файлы ".cpp" и ".h").
